This three-dimensional geometric morphometric dataset was published in Cardini and Elton (2017) and has since been used across geometric morphometrics and paleoanthropology as a useful large dataset for methods development and hypothesis generation. We removed Cercopithecus sclateri as that species was not included in 10Ktrees. "fulldataset.csv" includes metadata from Cardini and Elton (2017). "justLandmarks.csv" includes scientific name then the raw landmark data as lm1x, lm1y, lm1z, ... lm155x, lm155y, lm155z

This dataset contains 155 3D landmarks from 1,304 individuals across 23 species.


Dataset refernce:
